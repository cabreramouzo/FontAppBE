# Instrucciones del repositorio para Codex

Antes de analizar, modificar o probar este repositorio, lee `CLAUDE.md` completo y sigue
sus instrucciones como si estuvieran escritas directamente en este archivo.

`CLAUDE.md` es la única fuente de verdad para el contexto técnico, las decisiones de
arquitectura, los comandos de validación y la sección «No hacer». No dupliques aquí su
contenido: cualquier cambio en las instrucciones del proyecto debe hacerse allí para que
Claude y Codex utilicen siempre las mismas reglas.
